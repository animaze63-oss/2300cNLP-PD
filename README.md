# Steadyline — Landing Page

Static landing page for Steadyline (AI & workflow consulting for small teams).

- `index.html` — the page
- `assets/` — images, fonts, and scripts (React is bundled locally, no CDN needed)
- `netlify.toml` — Netlify config: no build step, publishes the repo root

## Deploy on Netlify
Connect this repo in Netlify, choose the `main` branch, leave the build command empty, and set the publish directory to `.` (already set in `netlify.toml`).
